# Privacy: what the assistant does with your data (preview)

**This describes the preview's current behaviour, from its code.** External services are described from their official documentation as of 2026-11-19, and may change. The Hebrew summary for users is docs/privacy-he.md.

## Data flow
```
Stick microphone ──(home Wi-Fi, plain HTTP, device key)──▶ Mac server
   one question's audio                                        │
                                                               ├─ speech detection + Whisper (local, on the Mac)
                                                               ├─ transcript + recent history ──▶ Claude Code ──▶ Anthropic
                                                               │      (Claude may use web search / web fetch)
                                                               ├─ reply text ──▶ Hebrew TTS (local) ──▶ WAV
Stick speaker ◀──(home Wi-Fi, plain HTTP, device key)── reply WAV
Claude Code notification hook (optional) ──(loopback)──▶ server ──▶ Stick: project-folder name only
```

## What goes where
| Data | Stays local | Sent out |
|---|---|---|
| **Microphone audio** (one question, recorded only while you press) | **Stick:** RAM only. **Mac:** `recordings/recording.wav` | No (it crosses your home network unencrypted) |
| **Transcript of the question** | `recordings/transcript.txt`; printed in the server's Terminal window | **To Anthropic**, in the Claude request |
| **Conversation history** (up to 6 recent exchanges, at most 4,000 characters) | Server memory only. Cleared after 15 minutes of silence, by the reset phrase, or when the server stops | **To Anthropic**, with each later question in that conversation |
| **Reply text** | `recordings/reply.txt`; printed in the Terminal window | Generated by Anthropic |
| **Web searches and fetched pages** (only if Claude uses them) | n/a | Searches run through Anthropic's service; the fetched page's content is processed by Anthropic; the website sees the request |
| **Reply audio** | `recordings/reply.wav`, `reply_for_stick.wav`; on the Stick, only in RAM while playing | No |
| **Reminders** (text, time, outcome) | `data/panel.db` (open reminders plus up to 100 finished); their audio in `data/reminders/` until no longer needed | No (synthesized locally) |
| **Claude Code notifications** (optional hook) | Server memory: at most 5, dropped after 5 minutes. Only `{kind, project folder name, session id, prompt id}` | No |
| **Device settings and last report** | `data/panel.db`; `/flash/device_cache.json` on the Stick | No |
| **Device key** | `secrets/device_key` (0600); `/flash/device_key.txt` | No, but it crosses your home network in clear text on every request |
| **Wi-Fi name and password** | Only on the Stick. UIFlow's Setup app prints them to the USB console while saving | No |
| **Stick backups and tool records** | Private folders on the Mac (0700/0600), until you delete them | No |

## How the Claude call is limited
Each question runs `claude -p` (Claude Code, under your Claude account), set up so that it doesn't inherit your own Claude Code setup:
* **Tools:** only web search and web fetch, explicitly allowed. Any other tool call is denied (`--permission-mode dontAsk`).
* **No MCP servers or claude.ai connectors:** **email, calendar and other connectors are disabled in the preview**, even if your account has them (`--strict-mcp-config`, `--disallowedTools "mcp__*"`).
* **None of your Claude Code settings, permission rules or hooks are loaded**, and hooks and skills are off (`--setting-sources project` in an empty private folder, `disableAllHooks`, `--disable-slash-commands`).
* **No `CLAUDE.md` instructions or auto memory** are loaded (`CLAUDE_CODE_DISABLE_CLAUDE_MDS`, `CLAUDE_CODE_DISABLE_AUTO_MEMORY`). The call runs in an empty private folder, not in the project.
* **Claude Code keeps no local copy:** no session transcript (`--no-session-persistence`) and no prompt history (`CLAUDE_CODE_SKIP_PROMPT_HISTORY`).

**How this was checked:** with Claude Code 2.1.288 and synthetic data.
* A canary `CLAUDE.md` was ignored.
* A redirected user hook didn't run.
* The tool list showed only WebSearch and WebFetch.
* Web search was permitted.
* No Claude Code project state was created.

An isolated test checks every flag. A different Claude Code version could behave differently. **Managed (organisation) settings still apply** if your account has them.

## What Anthropic keeps
**It depends on your account type and settings, so check your own.** According to Anthropic's documentation (2026-11-19):
* **Consumer accounts (Free, Pro, Max):** retention depends on the "help improve Claude" data-use setting: 30 days when it's off; up to 5 years, with possible use for training, when it's on. Content flagged by safety systems, and feedback you submit, can be kept longer.
* **Team, Enterprise and API accounts:** commercial terms; no training by default; standard retention of 30 days.

Sources:
* https://code.claude.com/docs/en/data-usage
* https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data
* https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data

**Claude Code telemetry:** separately, Claude Code may send usage metrics (not prompts) and, for some plans, error reports. It respects `DISABLE_TELEMETRY` and `DISABLE_ERROR_REPORTING` (see the data-usage page). This project doesn't change those settings.

## Retention and deletion of local data
| Data | Kept | How to delete |
|---|---|---|
| The last question's audio, transcript, reply text and reply audio (`recordings/`) | Until the next question overwrites them | Stop the server and delete the files |
| Conversation history | Memory only (see above) | Say the reset phrase, or stop the server |
| Terminal window output (transcripts and replies) | Until you close or clear the window | Close the window, or clear its scrollback |
| Reminders | Open ones, plus up to 100 finished | Cancel them in the panel. Removing the history means deleting `data/panel.db`, which also resets the panel settings |
| Stick backups and tool records | Until you delete them | Delete the folders yourself |
| Settings cache, key and Wi-Fi on the Stick | Until changed | Key and files with the USB tools; Wi-Fi through UIFlow |

**Deleting local files doesn't delete:**
* copies held by Anthropic (governed by your account);
* copies in your own backups (Time Machine, Stick backups);
* anything your own, separate use of Claude Code stored.

## Known privacy limitations of the preview
* **Content logging:** the server prints every full transcript and reply in its Terminal window, and keeps the last ones in `recordings/`.
* **Unencrypted home network:** someone who can observe your home network can read the audio, the replies and the device key.
* **Other people:** anyone near the Stick can press the button and ask. Tell people near it that it records when pressed.
* **No one-step delete:** there's no single command to delete all local data.
* **Model downloads:** Hugging Face logs requests (IP address, user agent). Set `HF_HUB_DISABLE_TELEMETRY=1` to reduce what the library sends.
